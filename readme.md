═══ PIPELINE (each stage can short-circuit) ═══
1. Preprocess: strip timestamps, IDs, IPs, hex, numbers, symbols; lowercase; normalize whitespace.
2. Regex classifier: known patterns -> category with high confidence.
3. Sentence-BERT embeddings + Logistic Regression for known categories. If max probability >= 0.70, return.
4. DBSCAN on embeddings of low-confidence logs: noise points = unknown anomalies; cluster them for the Anomaly Explorer.
5. LLM few-shot fallback (Claude API) returning strict JSON {category, severity, explanation, remediation}. If the key is missing or the call fails, degrade gracefully to category "Unknown" with low confidence. Never crash.
Categories: Database Error, API Failure, Login Failure, Payment Issue, Security Alert, Resource Usage, Workflow Error, User Action, Unknown.
Severity: Critical, High, Medium, Low (derive from category + log level + keywords).
Every classification returns: category, severity, confidence, classified_by ("Regex" | "BERT+LogReg" | "DBSCAN" | "LLM"), cleaned_text, is_known, pipeline_trace [{stage, matched, score}], explanation, remediation.
Load models ONCE at startup (FastAPI lifespan), never per request.
